# 图书管理系统（考核基座）

一个 JDK 原生的控制台图书管理程序：**零第三方依赖、零构建工具**，只需要 JDK 17+。

用于「AI Coding 上机考核」——考生在此基础上完成 1 个缺陷修复、1 个功能实现和 1 组测试。

> ⚠️ 这是考核基座，**刻意保留了一个缺陷（任务一：按书名搜索）和一处未完成的功能（任务二：删除图书）**，详见《01-题目文档.md》。

## 快速开始

```bash
# 运行程序（JDK 17+）
bash run.sh

# 运行测试
bash run-tests.sh
```

启动后程序预置 3 本演示图书（编号 1-3，第二本为已借出），自增编号从 4 开始。

## 目录结构

```
library-exam-base/
├── src/
│   ├── Book.java     图书实体（私有属性 + getter/setter）
│   ├── Library.java  核心逻辑（内存 ArrayList：添加/查看/搜索/借阅/归还）
│   └── Main.java     控制台菜单（Scanner 输入输出，逻辑委托 Library）
├── tests/
│   ├── Assert.java       零依赖断言帮助类
│   ├── TestRunner.java   零依赖测试运行器（类名 *Test + 方法名 test*）
│   └── LibraryTest.java  既有测试（回归网，请勿删改）
├── run.sh           一键运行程序
└── run-tests.sh     一键运行测试
```

## 设计约定

- **IO 与逻辑分离**：`Main` 只负责 `Scanner` 输入输出；`Library` 不依赖控制台，可被单测直接调用
- **消息文案由 `Library` 返回**（如 `借阅成功`、`图书编号不存在`），`Main` 只负责打印
- **测试约定**：测试类名以 `Test` 结尾、测试方法为无参 `public void` 且以 `test` 开头，使用 `Assert` 断言；TestRunner 自动发现，新增测试文件无需改 runner
- **菜单（修复任务二之后的目标形态）**：1 添加 / 2 查看全部 / 3 按书名搜索 / 4 借阅·归还 / 5 删除图书 / 6 退出
- 图书行格式：`编号:1  书名:Java入门  作者:张三  价格:59.5  状态:未借出`（价格为 double 原样输出）
